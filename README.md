# 래틀백 디벨롭 탐구 공부자료

Inertia 래틀백 디벨롭 탐구(받침 배치 탐구)를 설명하기 위한 단계별 공부자료 사이트.

- 사이트: https://naujin-dev.github.io/rattleback-study/
- 내용: 공부 순서, 1~9단계(회전 뒤집힘, 관성곱, 2배각 화살표, 흔들림 진동수, 선행연구 식, 준등방 적층, 구슬 받침, 숨은 질량 검사기, 수치 계산과 분석), 확인 문제, 참고 자료

## 파일

| 파일 | 내용 |
| --- | --- |
| index.html | 사이트 전체(한 페이지). 글, 수식, 스타일, 스크립트가 모두 들어 있다 |
| assets/ | 그림 5장(webp) |
| favicon.svg | 탭 아이콘 |
| .nojekyll | GitHub Pages가 파일을 그대로 내보내게 하는 빈 파일 |

## 고치는 법

저장소에서 index.html을 열고 연필 아이콘으로 고친 뒤 Commit changes를 누르면 1~2분 뒤 사이트에 반영된다.
